# 仙途挂机 · Idle Cultivation

一款零依赖的纯静态网页放置类修仙小游戏：**双击 `index.html` 即可运行**，无需安装、无构建步骤、支持离线。

玩法参考《梅尔沃放置》(Melvor Idle) 的动作 / 精通 / 命中制战斗 / 多商店 / 观星 / 种植设计，并结合《凡人修仙传》的境界 / 灵根 / 丹药体系。

- **运行方式**：双击 `index.html`，浏览器直接打开即可。进度自动本地存档，关闭页面后再次打开可结算最长 12 小时的离线收益。
- **技术栈**：原生 HTML / CSS / JavaScript，无任何外部依赖与素材。
- **代码结构**：`js/` 目录按「数据 / 状态 / 引擎 / 界面 / 入口」五层分离。

## 游戏内容一览

- **九大技能**：伐木 · 钓鱼 · 采矿 · 炼器 · 炼丹 · 战斗 · 修炼 · 阵法 · 灵植
- **单一动作槽**：同一时间只能做一件事，切换动作会打断当前进度（灵植生长为后台被动例外）
- **离线收益**：关闭页面最长 12 小时收益，上线后按与在线完全一致的逻辑结算
- **33 阶境界**：炼气 → 筑基 → 结丹 → 元婴 → 化神 → 炼虚，突破需对应丹药
- **阵法系统**：观星取星砂，点亮阵纹获得全局常驻加成
- **任务 / 背包 / 市集**：成就任务、100 格背包、四店铺采买与折价出售
