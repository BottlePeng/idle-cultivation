# 穿越星球 · Planet Crossing

一款零依赖的纯静态网页放置类修仙小游戏：**双击 `index.html` 即可运行**，无需安装、无构建步骤、支持离线。

玩法参考《梅尔沃放置》(Melvor Idle) 的动作 / 精通 / 命中制战斗 / 多商店 / 观星 / 种植设计，并结合《凡人修仙传》的境界 / 灵根 / 丹药体系。

- **运行方式**：双击 `index.html`，浏览器直接打开即可。进度自动本地存档，关闭页面后再次打开可结算最长 12 小时的离线收益。
- **技术栈**：原生 HTML / CSS / JavaScript，无任何外部依赖与素材。
- **代码结构**：`js/` 目录按「数据 / 状态 / 引擎 / 界面 / 入口」五层分离。

## 版本号

版本号是**三段式** `主.次.修`（例如 `1.20.123`），唯一来源是 [js/data.js](js/data.js) 里的 `const VERSION`，界面顶栏右上角与窗口标题都读它。

| 更新类型 | 命令 | 结果 | 判定标准 |
| --- | --- | --- | --- |
| 小更新 | `node tools/version.js patch` | `1.20.123 → 1.20.124` | bug 修复等，**不影响存档** |
| 机制更新 | `node tools/version.js minor` | `1.20.124 → 1.21.0` | 新增/改动机制，**影响存档**，修订归零 |
| 大型更新 | `node tools/version.js major` | `1.21.0 → 2.0.0` | DLC / 全新机制，**需重开游戏**，次/修归零 |

`node tools/version.js` 可随时查看当前版本。每次递增都会自动把新版本写进 `packaging/electron/package.json`，
因此 `npm run build` 产出的文件名会自动带上版本：`PlanetCrossing-<版本>-Portable.exe`（打包前的 `prebuild` 还会再同步一次，防止手改漏掉）。

## 打包桌面 exe

Electron 壳代码与游戏源码完全隔离在 `packaging/electron/`，不修改任何 JS/CSS/HTML；游戏文件通过 `extraResources` 注入到 `resources/game`。

```bash
# 首次：安装依赖（仅需执行一次）
cd packaging/electron
npm install

# 每次构建：npm 会先跑 prebuild 同步版本号，再调用 electron-builder
npm run build
# 产物：packaging/electron/dist/PlanetCrossing-<版本>-Portable.exe
```

> **窗口模式**：启动即「窗口化全屏」（无边框、铺满主屏实际尺寸，含任务栏区域），按 `F11` 在窗口化全屏与 1180×760 窗口之间切换。
>
> **存档位置**：Electron 版存档在 `%APPDATA%\Planet Crossing\Local Storage\leveldb`（与浏览器 `file://` 存档不互通，换端需重新开局；旧版 `IdleCultivation` 目录下的存档不会自动迁移）。`main.js` 用 `app.setPath('userData', ...)` **显式固定沿用这个目录**，与当前 productName 一致；日后即使再改名，也不会切换目录导致老玩家丢档。
>
> **切换其他打包方式**：`packaging/` 下各子目录彼此独立，想换 Tauri / WebView2 C# 壳直接新建子目录即可，互不干扰。

## 游戏内容一览

- **十大技能**：伐木 · 钓鱼 · 采矿 · 炼器 · 炼丹 · 战斗 · 修炼 · 阵法 · 灵植 · 入世（技能等级**无上限**，经验按 `base × lvl^pow` 持续增长）
- **单一动作槽**：同一时间只能做一件事，切换动作会打断当前进度（灵植生长为后台被动例外）。新档与读档默认空闲，不会自动开启打坐；只有玩家主动点开的采集 / 配方动作会在重新进入时恢复并继续离线结算（旧档遗留的默认打坐会被清空，v2.14.3）
- **离线收益**：关闭页面最长 12 小时收益，上线后按与在线完全一致的逻辑结算
- **96,533 阶境界**：炼气 → 筑基 → 结丹 → 元婴 → 化神 → 炼虚（33 阶，突破需对应丹药）→ 太上境（一层 ~ 九万六千五百层，共 96,500 层，纯修为 + 概率突破）；前六境修为需求按「纯修炼挂机约 500 小时晋入太上境一层」定标（v1.9.4，见[标定数据](./document/机制-修炼与境界.md#附录-a500-小时定标数据)）
- **五行灵根与悟性**：金木水火土对应炼器/伐木/钓鱼/炼丹/阵法，属性值随做工成长；悟道丹提升悟性，每点永久 +1% 修炼速度与突破率
- **中期关卡**：冲击炼虚大圆满需五行灵根全部达到 Lv.100，之后开启太上境无边阶梯
- **阵法系统**：观星取星砂，点亮阵纹获得全局常驻加成
- **问道指引**：轻量新手教学清单，覆盖开局 10 个关键动作（打坐修炼 → 采集 → 背包 → 市集 → 购买 → 战斗 → 洞天建造 → 阵纹 → 突破 → 首次穿越）。右侧常驻小卡片 + 侧栏目标入口金色脉冲高亮，不弹模态框；玩家实际做出行为才自动打勾，完成即发星砂 / 生命之种 / 丹药（不发灵石）。可跳过 / 收起 / 随时重开，跳过或完成后不再打扰；旧档按现有进度推断已完成步骤（标注「旧档推断」）且不补发奖励（v2.14.0）
- **任务 / 背包 / 市集**：71 条成就任务分 6 个阶段（初入仙途 → 太上高階），从首次采集覆盖到太上境满级，进度挂钩境界 / 技能 / 锁妖塔 / 穿越 / 朝代职位 / 道侣 / 阵法 / 洞天建设度 / 精通 / 信徒 / 秘境；新任务奖励以生命之种、星砂、丹药、装备、神品信徒为主，不再发放灵石。背包基础 100 格，可用灵石扩容至 220 格（每次 +2 格，`300 × 1.14^n` 递增，满级累计约 556 万灵石）。市集扩展为 6 店 139 项，高阶商品按技能等级 / 境界 / 洞天建设度 / 锁妖塔 / 穿越次数条件解锁；市集进价与出售加成使用同一行情倍率，种子按成熟收益定价、炼虚丹原料使用覆盖价，买种 / 买料 → 加工 → 出售不再有稳定正收益（v2.13.0）
- **七日签到**：侧栏「📅 签到」，按本地日期每日限领一次，连续 7 天一轮、第 7 天领完回到第 1 天；断签从第 1 天重来，系统日期回退时锁定签到且不丢进度。奖励为灵石 / 灵力 / 星砂 / 生命之种 / 丹药 / 装备，第 7 天额外送 1 位神品信徒（招贤殿无空位时暂存，腾位后自动补发）。背包格位不足时整单拒签，不发半份奖励；不占用动作槽、不受离线结算影响

- **世界 · 洞天**：8 种地形（平原/林地/山岳/水泽/秘境/火山/荒漠/雪原）共 100 种建筑，按地形成链、各有专精方向；被动产出粮食、木材、石料、灵石、灵力、星砂，并提供修为、速度、掉落、精通等 17 条全局加成通道（参考梅尔沃城镇，不占用动作槽）
- **信徒 · 五行上阵 / 职业**：在洞天营造「招贤殿」后可招募信徒（20 种身份、4 个品阶）。每位信徒五行齐全，并随机拥有 1 个主属性（强度约为副属性的 2.0~2.4 倍，副属性与主属性强度都由品质决定）；每个主动任务有一个信徒席位，主属性命中吃高加成，其余四种副属性命中吃基础加成，两者都作用于动作速度 / 经验 / 掉落。上阵总数仍受招贤殿等级限制（容量 = 8 + 6×(等级−1)，Lv.5 为 32 格，见战阵），一位信徒只能挂一个任务或一个朝代职位（二选一）；仓库卡片可遣散（二次确认，驻守 / 任职者自动解除），招募费按历史峰值计算、遣散不降价（v2.9.2）。v2.15.0 起每位信徒额外获得 1 个固定职业（皇帝 / 皇后 / 丞相 / 将军 / 皇妃 / 大统帅 / 右统帅 / 左统帅），只有职业匹配才能担任对应朝代职位；招募按 8 职业基础等权 + 缺员补正抽取，面板显示职业分布，职位下拉只列匹配候选
- **道侣 · 化道**：信徒仓库卡片内的「💞 道侣」区块，把一位同修「化道」纳为道侣——对方从仓库永久移除（其在任务席位与朝代职位上的身份自动解除，原有道侣关系全部寡妇化），纳者则永久保留其加成。每人最多 7 位、结契后不可解除。单段加成 = 对方主属性强度 ×50%，同主属性再 +2%、对方属性生我再 +1%，合计作为乘数放大该信徒的速度 / 经验 / 掉落加成（神品同主 7 段约 ×1.686），不影响朝代职位与洞天产出；被消耗者不退还招募费，亡故记录仍永久占位（v2.11.0 对称绑定 → v2.12.0 化道式单向）
- **信徒 · 战阵**：招贤殿解锁后的独立战斗玩法，共 10 个位置——前排 5 个通用位，后排 5 个职业专位（皇帝 / 皇后 / 丞相 / 将军 / 皇妃，各限 1 人且只收对应职业）；招贤殿每级 +2 位（Lv.5 满 10）。60 关分 6 章，10 位信徒自动对战 1 只妖兽，沿用现有命中 / 闪避 / 减伤公式与 30% 敌方减伤上限，但不读玩家装备 / 阵法 / 洞天加成。首通给星砂 / 生命之种 / 粮食 / 木材 / 石料，章节 Boss 首通额外掉中级丹药与中档装备（最高紫檀档）；重复挑战只给 35% 灵石 + 账号级「战修经验」，**不产**星砂 / 种子 / 洞天资源 / 玩家战斗经验 / 精通，不做第二座金币塔、不新增货币。每日妖王（每天 1 次）与扫荡（每天 3 次）提供额外资源；战阵独立于任务席位与朝代职位（同一信徒只能有一种身份），占用单一动作槽，离线不战斗（v2.16.0）
- **战阵重伤与疗伤**：战阵中信徒生命归零立即自动下阵并进入重伤，槽位变空（不留幽灵队员）；场上无人时按现有失败流程判负。重伤期间战阵、任务上阵、朝代职位全部不可选（下拉直接不列出，引擎二次拒绝并提示原因）。恢复只能消耗灵力（按缺失生命 0.6 灵力 / 1%，从 0 回满约 60，单次封顶 200）与 1 枚聚气丹（既有低阶丹药，不新增道具），灵力或丹药不足时拒绝且不扣资源；**没有定时 / 自然 / 离线自愈**。信徒卡片红边 + 「重伤」标识，战阵页与信徒仓库都提供疗伤按钮和费用预览；重伤标记存信徒实例 `injured`，旧档缺省视为健康，遣散 / 化道后随实例清除（v2.20.0）
- **战阵生命延续**：取消「过关回满血」。通关、失败、自动连战进入下一关、扫荡以外的重复挑战都不回血，剩余生命按比例存在信徒实例 `hpPct` 上——离开面板再回来、切换动作中止后再挑战、读档重进都按上次剩下的算，只有疗伤能回满。编成槽显示当前 / 最大生命，信徒卡片未满血时显示「生命 xx%」并可随时疗伤；伤兵区同时列出残血与重伤者，资源不足时写明缺灵力还是缺聚气丹、去哪补。自动连战在任一在场信徒低于 25% 生命时自动暂停并提示，避免把残血信徒送进下一关（手动挑战不受限制）（v2.21.0）
- **装备词条**：装备改为实例化，同名同品质的两件不再共用属性——每件产出时按基础价值所属品质随机 roll 1~4 条词条，存进实例并随存档保留。词条池覆盖现有加成通道：攻 / 防 / 生命 / 命中 / 闪避为固定值，工作速度 / 经验获取 / 额外产出 / 灵力恢复 / 战斗掉落为百分比（同名全身合计封顶 15%），数值锚定装备自身主属性，低阶装备无法靠词条越阶。炼器、市集、战斗掉落、宝箱、任务、签到、洞天首通、兑换码全部经 `invAdd` 统一 roll；旧档装备读档时一次性补 roll。背包按价值降序展示装备卡片（品质色、基础属性、词条胶囊、与当前同部位的属性差）；不含洗练 / 重铸（v2.22.0）
- **语言切换**：设置 → 通用提供「中文 / English」，选择后立即生效并保存到存档，刷新或重开保持上次语言。翻译层零依赖：7 个字典分片共 1341 条精确译文 + `#` 数字模板 + 术语兜底，覆盖全部物品、任务、市集、阵法、妖兽、建筑与机制长文；`textContent` / `innerHTML` 写入入口统一本地化，英文模式不再残留中文（v2.23.7）
- **穿越星球**：占用动作槽的主动小游戏，四周生成灵石 / 星砂 / 材料 / 生命之种（50% / 30% / 19% / 1%）；吸收每件消耗 0.5 灵力，巡航时生成每件消耗「灵气浓度」，穿越后单件消耗逐次 -10%（下限 0.2，越穿越耐用）；浓度以 `xx.x% (当前/上限)` 显示，只有停止运转才恢复；上限与恢复随引力塔等级和穿越次数双增长；「穿越」只消耗灵气浓度（首次 10000，之后 1.6 倍 / 第 11 次起 1.12 倍），朝代：清 → 明 → 元 → 宋 → 唐 → 南北朝 → 两晋 → 三国 → 周 → 商 → 夏 → 古一纪……（v1.9.9）
- **异界裂缝**：穿越星球的门槛战。新档自带一道未修复裂缝，每次穿越成功后立刻生成下一道；裂缝未修复时穿越按钮置灰并提示「需先修复异界裂缝」，击败（修复）后才能继续穿越；强度按层级（生成时穿越次数）成长，阵亡不惩罚、不清零穿越次数，回血后可原地重试；修复给少量灵石 / 星砂 / 战斗经验；占用全局动作槽，与星球、锁妖塔、普通战斗互斥（v2.2.0）
- **五行属性裂缝**：穿越星球界面的常驻玩法，与异界裂缝互相独立。始终同时存在 3 道「金 / 木 / 水 / 火 / 土·时空裂缝」（属性各自随机，允许重复），每 3 小时按真实时间整轮覆盖刷新（不做离线补刷，离线超过 3 小时回来直接换一轮），面板显示下一次刷新倒计时；点击进入战斗，修复后该位置留空到下一轮刷新；奖励按对应工作（金→炼器输入材料、木→木材、水→渔获、火→药材、土→星砂）的当前等级档位发放 1~5 件；强度同时随该工作等级与穿越次数上升，单次伤害不超过当前生命上限的 16%；阵亡不消耗裂缝、不降级，回血后可重试；不参与穿越门槛、不影响穿越按钮，但战斗占用全局动作槽（v2.3.0）
- **裂缝怪物**：穿越星球界面的常驻单体强敌，与异界裂缝、五行属性裂缝三套独立。同时只存在 1 只，每 24 小时按真实时间整轮刷新；击败后不立刻重生，等原定刷新时间到来（离线超过 24 小时回来只换一轮，不补刷）。怪物存在时「开启运转」置灰并提示「需先击败裂缝怪物」，但**不拦穿越**、不影响异界裂缝与五行裂缝；强度按生成时的穿越次数成长，同 t 下生命 / 攻击 / 命中 / 闪避 / 减伤 / 出手间隔均不高于异界裂缝，单次伤害不超过当前生命上限的 14%；击败给灵石 + 星砂（低于同层锁妖塔）；阵亡不消耗、不降强度，可回血重试；刷新时若正在运转则延后到停止后生成；战斗占用全局动作槽（v2.4.0）
- **洞天 · 朝代**：消耗新资源「生命之种」召唤不同年代的生灵（年代沿用穿越星球的朝代序列，0 次穿越只能召清朝/明朝，之后每次穿越多解锁一个年代）。每个朝代是独立人口池（万级，显示统一为 `3.0万 / 12.0万` 这类格式），每 1 小时结算一次（内部 6 个 10 分钟子步，每小时收益与人口曲线与旧版一致），按人口产出粮食与年代对应的主资源（木/石/灵石/星砂）；人口向上限逼近增长，上限只能通过合成同名朝代提升（目标获得被合者 50% 人口与 50% 上限，被合者随即消失并腾出朝代位）。朝代位 = 「小世界」等级 × 5，小世界首建只收灵石 6000、第 2 级起要材料，建造门槛为元婴期。生命之种来自星球飞行物（1%）、五行属性裂缝（50%）、异界裂缝与裂缝怪物（必掉）。召唤/合成不占用动作槽，结算走 `worldTick` 同一通道、离线同样推进（受 12 小时上限约束）。每个朝代可任命 8 个永久职位（👑 皇帝 / 🌸 皇后 / 📜 丞相 / ⚔️ 将军 / 🎀 皇妃 / 🎖️ 大统帅 / 🛡️ 右统帅 / 🗡️ 左统帅），不可取下 / 更换，按品阶为整朝粮食与主资源提供 +5%~+24% 乘算加成（神品满编合计 +85%，×1.85）；职位不占用招贤殿上阵位，但一位信徒只能有任务或职位一个身份；朝代被合成时所有在任职位随朝代一起永久消失（有职位在任时两次确认，不退还招募费）（v2.9.5）
- **侧栏分组**：侧栏按功能分为「主要 / 修炼 / 战斗 / 生产 / 洞天与朝代 / 系统」6 个可折叠分组，点击组头收起 / 展开；折叠状态存 `state.ui.sidebarClosed` 并落盘，重开游戏保持上次的样子。折叠时组头显示入口数量 + 最多 6 个图标窥视 + 待处理亮点，当前面板所在组有金色高亮；未归组的新技能自动进「其他」，新增入口只需加进 `SIDEBAR_GROUPS`，不用改布局代码。窄屏 78px 只留图标，≤820px 转为横向滚动（v2.17.0）
- **全局滚动条**：所有滚动容器统一为 6px（≤820px 为 4px）细滚动条，轨道透明；滑块默认隐藏，滚动中或鼠标悬停容器时显示，停手 900ms 后 0.45s 淡出。覆盖主内容区、侧栏横/竖滚动、右侧信息栏、弹窗、背包、日志与后续新增的 overflow 容器；只用一个 document 捕获监听切换 `.is-scrolling`，不参与 `setHTML` / `updateBars`（v2.18.0）
- **提醒视觉分级**：侧栏入口徽标、分组头亮点、折叠窥视点与面板提示条统一四档——可领取（任务 / 签到 / 锁妖塔 / 战阵待入库）与阻塞（裂缝未修复、裂缝怪物存活）为金橙 / 珊瑚渐变徽标 + 2.4s 细脉冲环，教学类（问道）为静态蓝标不脉冲，动作进行中仍是静态绿点；折叠后组头与窥视图标保留亮点，≤1080px 图标模式在入口右上角补点。状态由 `sidebarEntryMeta` 现算、不落存档，动效只改 `transform` / `opacity`，面板列表不做循环动画，`prefers-reduced-motion` 下全部关闭（v2.19.0）
- **设置与测试控制台**：侧栏新增「🔧 设置」，作为后续设置项的落位骨架（分组容器 + 占位条目），本次开放「兑换码」：输入框 + 兑换按钮 + 成功/失败提示。校验规则集中在 `js/data.js` 的 `REDEEM`（只保存 FNV-1a 哈希，不存明文码），兑换成功后本次运行解锁「🔬 测试控制台」——可调灵石/灵力/星砂/生命之种、粮食木材石料、修为与境界阶数、技能等级与精通、洞天建筑（含引力塔）、星球浓度与穿越次数、锁妖塔层数、三套裂缝的重置/击败状态，以及复用离线结算的时间快进。解锁状态是会话级（不写入存档），刷新或重开即失效，存档中无相关字段；「重开游戏」入口已从顶栏迁入设置页「存档 · 危险操作」分组（默认暗红虚线、低对比，悬停/聚焦转亮红；二次确认弹窗带 ⚠ 警示条与红色高亮），顶栏只保留「保存」；「通用」分组提亮为设置页视觉主体（v2.14.2）
- **锁妖塔**：无尽层单场挑战，位于战斗之后；每层敌人属性按层数幂律成长，击败后先领奖再进下一层；灵石为主、星砂 / 丹药 / 材料为辅，每 5 层里程碑、每 10 层追加材料；层数与最高层永久保存、永不重置，阵亡不降层可原地重试；挑战占用全局动作槽且不产生离线收益（v2.1.0）
