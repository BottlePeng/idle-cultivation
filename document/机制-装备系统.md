# 机制 · 装备系统

> 相关代码：`js/data.js`（`EQUIP_SLOTS`、`ITEMS[type:'equip']`）、`js/engine.js`（`calcStats/equipGear/unequipSlot`）、`js/main.js`（`gearequip/gearsell` 事件）

装备是**战斗属性的主要来源**：通过锻造或市集获得，穿戴后直接累加到攻/防/命/闪/生命。

> v2.22.0 起装备改为**实例化**：同名装备不再共用同一份属性，每件会额外 roll 出 1~N 条随机词条，详见 [机制 · 装备词条](./机制-装备词条.md)。

---

## 1. 部位（`EQUIP_SLOTS`）

| 部位 | id | 说明 |
| --- | --- | --- |
| 法宝 | `weapon` | 主攻击来源 |
| 灵甲 | `armor` | 防御与生命 |
| 法冠 | `helmet` | 防御与命中 |
| 灵靴 | `boots` | 闪避与命中 |
| 玉佩 | `amulet` | 防御与生命 |
| 灵戒 | `ring` | 攻击与闪避 |

**每个部位同时只能装备一件**（`state.equip[slot] = uid`）。

装备实体存放在 `state.gear = [{ uid, id, affixes }]`：`id` 指向模板，`affixes` 是该实例独有的词条。装备**不再进入** `state.inv` 堆叠，每件独立占 1 个背包格，已穿戴不占格。

---

## 2. 属性字段

装备物品（`type: 'equip'`）可携带以下字段，`calcStats` 会逐件累加：

| 字段 | 作用 |
| --- | --- |
| `slot` | 所属部位（必填，决定可装备位置） |
| `atk` | 攻击力 |
| `def` | 防御力（转为伤害减免） |
| `hit` | 命中 |
| `ev` | 闪避 |
| `hp` | 生命上限 |
| `value` | 售价基准（市集出售 ×0.55，购入 ×1.8） |

以上是**模板基础值**。实例上的 `affixes` 会在 `calcStats` 中叠加：固定值词条（攻/防/命/生命/闪避）直接加到对应属性；百分比词条（工作速度/经验/额外产出/灵力恢复/战斗掉落）走全局乘区，同名合计封顶 15%。模板本身不会被词条改写。

## 4. 穿脱逻辑

### 4.1 装备（`equipGear(uid)`）

1. 按 `uid` 在 `state.gear` 中查实例，校验 `type === 'equip'`；
2. 若该实例已穿戴 → 忽略；
3. 直接写入 `state.equip[slot] = uid`；
4. 被替换下来的旧装备**仍留在 `state.gear`**（未穿戴状态），词条与实例都完整保留，不会复制、不会重 roll。

> 旧接口 `equipItem(itemId)` 仍保留，内部会找同 `id` 的未穿戴实例并转调 `equipGear`，兼容旧调用点。

### 4.2 卸下（`unequipSlot(slot)`）

- 仅把 `state.equip[slot]` 置为 `null`；实例仍留在 `state.gear`，回到背包卡片列表。
- 不存在「放回背包失败」问题：装备本来就没有离开实例数组，也不占已穿戴时的格子。

> 装备变更后需调用 `clampHp()` 重新钳制当前生命（生命上限可能变化）。

## 5. 获取途径

所有来源最终都通过统一的 `invAdd(id, qty)` 发放，装备会被路由到 `grantEquip → makeGear → rollGearAffixes`，保证每件都带词条：

1. **炼器锻造**：`RECIPES.crafting` 中的 `forge` 配方（见 [生产技能](./机制-生产技能.md)）。
2. **市集购入**：装备坊（`shopCat = 'equip'`），加价 1.8 倍。
3. **战斗掉落**：妖兽 / 章节 Boss / 异界裂缝。
4. **任务与里程碑**：如「樵夫之始」奖励铁剑、「矿脉之心」奖励铁冠。
5. **宝箱、签到、洞天首通、兑换码**等其余发放点。

> 背包容量按「每件 1 格」校验；不足时整批不发放。

## 6. UI 表现

- **右侧角色卡「装备」区**：六个槽位，显示已装备图标、名称、品质色与词条胶囊，点击可卸下。
- **背包**：装备不再以图标堆叠展示，而是按价值降序排列成卡片：品质色名称、部位、基础属性、词条胶囊、与当前同部位装备的属性差，以及「装备 / 出售」按钮。
- **属性对照**：卡片对比行显示穿上后攻/防/命/闪/生命的变化；右侧「伤害 / 命中 / 闪避 / 减伤 / 生命上限」即时更新。
- **市集与奖励预览**：只展示模板基础属性，具体词条在获得时生成。

## 7. 扩展指引

- 新增装备：在 `ITEMS` 追加 `type:'equip'` 条目（必须有 `slot`），并可在 `RECIPES.crafting` 加对应 `forge` 配方、或在 `SHOPS` 中上架。**不要**写入实例词条，产出时自动 roll。
- 新增基础属性维度：需同步 `calcStats` 的累加、`gearStat`、装备卡片与对比键表。
- 新增词条类型：在 `AFFIX_POOL` 加条目并在对应全局乘区接入效果，详见 [机制 · 装备词条](./机制-装备词条.md)。
- 套装 / 强化 / 洗练等进阶机制目前**不启用**，保留扩展空间。
