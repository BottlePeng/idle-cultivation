# 机制 · 装备系统

> 相关代码：`js/data.js`（`EQUIP_SLOTS`、`ITEMS[type:'equip']`）、`js/engine.js`（`calcStats/equipItem/unequipSlot`）、`js/main.js`（`equip/unequip` 事件）

装备是**战斗属性的主要来源**：通过锻造或市集获得，穿戴后直接累加到攻/防/命/闪/生命。

---

## 1. 部位（`EQUIP_SLOTS`）

| 部位 | id | 说明 |
| --- | --- | --- |
| 法宝 | `weapon` | 主攻击来源 |
| 灵甲 | `armor` | 防御与生命 |
| 法冠 | `helmet` | 防御与命中 |
| 灵靴 | `boots` | 闪避与命中 |
| 玉佩 | `amulet` | 防御与生命 |
| 灵戒 | `ring` | 攻击与闪避 |

**每个部位同时只能装备一件**（`state.equip[slot] = itemId`）。

---

## 2. 属性字段

装备物品（`type: 'equip'`）可携带以下字段，`calcStats` 会逐件累加：

| 字段 | 作用 |
| --- | --- |
| `slot` | 所属部位（必填，决定可装备位置） |
| `atk` | 攻击力 |
| `def` | 防御力（转为伤害减免） |
| `hit` | 命中 |
| `ev` | 闪避 |
| `hp` | 生命上限 |
| `value` | 售价基准（市集出售 ×0.55，购入 ×1.8） |

## 4. 穿脱逻辑

### 4.1 装备（`equipItem`）

1. 校验物品存在且 `type === 'equip'`，背包持有 ≥1；
2. 从背包移除 1 件；
3. 若该部位已有装备 → **自动退回背包**（不丢失）；
4. 写入 `state.equip[slot]`。

### 4.2 卸下（`unequipSlot`）

- 将该部位装备放回背包，清空各槽位。
- 若背包已满，放回失败时按实现处理（不覆盖已有装备）。

> 装备变更后需调用 `clampHp()` 重新钳制当前生命（生命上限可能变化）。

---

## 5. 获取途径

1. **炼器锻造**：`RECIPES.crafting` 中的 `forge` 配方（见 [生产技能](./机制-生产技能.md)）。
2. **市集购入**：装备坊（`shopCat = 'equip'`），加价 1.8 倍。
3. **任务奖励**：如「樵夫之始」奖励铁剑、「矿脉之心」奖励铁冠。

---

## 6. UI 表现

- **右侧角色卡「装备」区**：六个槽位，显示已装备图标与名称，点击可卸下。
- **背包**：装备类物品点击弹出操作菜单（装备 / 出售）。
- **属性对照**：穿上后右侧「伤害 / 命中 / 闪避 / 减伤 / 生命上限」即时更新。

---

## 7. 扩展指引

- 新增装备：在 `ITEMS` 追加 `type:'equip'` 条目（必须有 `slot`），并可在 `RECIPES.crafting` 加对应 `forge` 配方、或在 `SHOPS` 中上架。
- 新增属性维度：需同步 `calcStats` 的累加与右侧角色卡展示。
- 套装 / 强化等进阶机制目前**不启用**，保留扩展空间。
