# 机制 · 背包系统

> 相关代码：`js/data.js`（`ITEMS`）、`js/engine.js`（`invCount/invHas/invSlotsUsed/invFull/invCanAdd/invAdd/invRemove/sellItem`）、`js/ui.js`（`renderBag/updateInvQty`）、`js/main.js`（`invslot/filter/togglesell/sell/sellall`）

背包是**资源与物品的中枢**：采集、炼制、战斗掉落的产物都汇入背包，再由使用 / 装备 / 出售分流。

---

## 1. 容量模型

**背包容量以「物品种类数」计**（而非总数量），上限 `CONFIG.INV_SLOTS = 100`。

```
invSlotsUsed() = 数量 > 0 的物品种类数
invFull()      = invSlotsUsed() >= 100
invCanAdd(id)  = 已有该物品 ? true : invSlotsUsed() < 100
```

- **同类堆叠**：同一物品 id 只占 1 格，数量可无限叠加（`state.inv[id] = 数量`）。
- 采集循环中若产出的物品是**新种类**且背包已满 → 动作进入「等待」而非中断（见 [动作槽与离线收益](./机制-动作槽与离线收益.md)）。

---

## 2. 物品类型（`ITEMS[].type`）

| type | 说明 | 可执行操作 |
| --- | --- | --- |
| `material` | 材料 | 出售 |
| `food` | 食物 | 食用（回血）、出售、设为自动进食 |
| `pill` | 丹药 | 使用（聚气/疗伤）、出售；`use:'break'` 的丹药仅突破时自动消耗 |
| `equip` | 装备 | 装备、出售 |
| `seed` | 种子 | 用于灵植种植、出售 |

物品字段：`name / icon / value / desc`，食物含 `heal`，丹药含 `use`，装备含 `slot` 与属性，种子通过 `FARM_SEEDS` 关联。

---

## 3. 基本操作

| 操作 | 函数 | 说明 |
| --- | --- | --- |
| 增加 | `invAdd(id, qty)` | 满格且为新种类时返回 false；同时累加 `stats.gained[id]` |
| 移除 | `invRemove(id, qty)` | 数量归零则删除该键 |
| 查询 | `invCount(id)` / `invHas(id, qty)` | 数量 / 是否足够 |
| 出售 | `sellItem(id, qty)` | `qty < 0` 表示全部出售 |

出售价：

```
sellPrice(id) = max(1, floor(value × SELL_RATIO(0.55) × (1 + formBonus('sell'))))
```

- 聚宝阵「出售价」阵纹可提升出售收益（每级 +2%，上限 +20%）。

## 4. 界面与交互

### 4.1 背包面板

- 按 `ui.invFilter` 筛选：全部 / 材料 / 食物 / 丹药 / 装备 / 种子等。
- 每格显示图标、名称与数量；数量走 `updateInvQty()` 增量刷新（`data-qty` 节点）。
- 容量显示为 `已用种类 / 100`（侧栏按钮与面板头部）。

### 4.2 出售模式（`ui.invSellMode`）

- 开启后，**点击格子直接卖出 1 个**（跳过弹层，快速清仓）。
- 关闭时，点击格子弹出**操作菜单（popover）**。

### 4.3 操作菜单（popover）

| 物品类型 | 菜单项 |
| --- | --- |
| 食物 | 食用、出售 1、全部出售 |
| 丹药（非 break） | 使用、出售 1、全部出售 |
| 丹药（break） | 提示需在修炼面板突破时使用 |
| 装备 | 装备、出售 |
| 材料 / 种子 | 出售 1、全部出售 |

> 打开弹层时 `handleClick` **提前 return，不重绘整树**，避免弹层被销毁。

### 4.4 事件绑定

| `data-act` | 行为 |
| --- | --- |
| `filter` | 切换筛选 |
| `invslot` | 出售模式→卖 1；否则弹菜单 |
| `togglesell` | 切换出售模式 |
| `sell` / `sellall` | 卖指定数量 / 全部 |
| `eat` / `use` / `equip` / `unequip` | 对应操作 |
| `closepop` | 关闭弹层 |

## 5. 与其他系统的关系

```
采集 / 炼制 / 掉落 ──invAdd──► 背包 ──┬─ 使用(食物/丹药) ─► 回血 / 修为
                                      ├─ 装备 ──────────► 战斗属性
                                      ├─ 种植(种子) ─────► 灵植地块
                                      └─ 出售 ──────────► 灵石 ─► 市集/突破
```

- **背包满**会阻塞「新增种类」的产出，因此长挂机前应清理或出售冗余物品。

---

## 6. 扩展指引

- 新增物品：在 `ITEMS` 追加并指定 `type`；若为新类型，需在筛选与 popover 逻辑中登记。
- 若未来需要「按数量上限」而非「按种类上限」，需改动 `invSlotsUsed` 语义并同步全部调用点。
- 装备/丹药的特殊操作按 `type` 与 `use` 字段分流，新增类型时注意补齐菜单分支。
