# 机制 · 语言切换

> 版本：v2.23.7 ｜ 配置：`js/i18n.js` + `js/i18n-part-1~7.js` ｜ 状态：`state.lang`（`js/state.js`）｜ 入口：设置 → 通用

界面支持**中文 / English** 两种语言，默认中文；切换后立即生效并写入存档，刷新或重开保持上次选择。

## 1. 存储与迁移

- `state.lang`：`'zh'` | `'en'`，顶层字段，随存档持久化。
- `defaultState()` 默认 `'zh'`；`mergeState` 只接受 `'en'`，其余（含旧档缺失、异常值）一律回落 `'zh'`。
- 旧档**无需迁移动作**：没有 `lang` 即视为中文，不会覆盖其他字段。
- 语言属于界面偏好，不参与任何数值计算，也不影响任务、市场、战斗等判定。

## 2. 翻译层

`js/i18n.js` 采用「中文原文为 key」的英文字典：

- `t(中文)`：英文模式返回译文；未收录时**回退中文**，因此新增文案漏翻不会报错、不会出现空字符串。
- `isEn()`：当前是否英文。
- `tFloor(n)` / `tStage(n)`：楼层 / 阶数的中英模板。
- `applyStaticI18n()`：同步 `index.html` 中带 `data-i18n` / `data-i18n-title` 的静态节点，并更新 `<html lang>` 与窗口标题。

字典集中在 `I18N_EN`，新增文案只需补一条中文→英文映射；无需改动数据模板。

## 3. 切换流程

1. 设置 → 通用点击「中文 / English」；
2. 两个入口都会调用 `setLang(lang)`：
   - `main.js` 的 `setlang` 事件（常规路径）；
   - `i18n.js` 自带的 document 点击监听（兜底：即使运行环境里 `main.js` 是旧缓存、没有 `setlang` 分支，只要语言按钮已渲染就能切换）；
3. 写入 `state.lang` 并立即 `saveState()`；
4. `applyStaticI18n()` 刷新静态 DOM，`renderAll()` 整树重绘；
5. `setHTML` 依据内容签名判断，文案变化必然触发重绘；`updateBars` 只更新宽度与数值占位，不受语言影响。

> 两条路径同时触发时 `setLang` 幂等，最多多一次重绘。切换后按钮高亮、标题与侧栏立即变化，可据此判断是否真正写入。

## 4. 当前覆盖范围（v2.23.7，全量）

- 导航、顶栏、设置、背包、市集、右栏、装备、词条、品质、按钮与提示；
- 200+ 物品（材料/鱼/矿/锭/草药/丹药/种子/装备）的名称与描述；
- 71 条任务名称、描述与阶段；139 项市集商品名称与长描述；
- 阵法与阵纹、妖兽/裂缝怪物、约 100 座洞天建筑的名称与说明；
- 各面板的长段机制说明、动态拼接长句、境界名、朝代名、单位（万/亿 → k/M）。

实现方式分三层：

1. **精确字典**：`js/i18n-part-1~7.js` 共 1341 条，由数据/渲染文本抽取后翻译，覆盖固定文案；
2. **数字模板**：运行时把数字归一化为 `#` 再查字典，因此「第 3 层」「生命 26 / 26」等拼接句也能命中；
3. **兜底翻译**：`autoEn()` 处理中文数字单位与常用术语，最后清除残留汉字，保证英文模式不出现中文。

全局在 `textContent` 与 `innerHTML` 的写入入口做本地化，覆盖面板的增量刷新（锁妖塔、穿越星球等）；每秒一次的 DOM 清扫作为最后保险。

> 说明：兜底层对极少数未收录长句输出的是「术语级」英文，语义可读但不追求文学润色；新增文案应优先补进字典分片。

## 5. 扩展指引

- 新增界面文案：优先写成中文并调用 `t('中文')`；同时在 `I18N_EN` 或分片字典补译文。
- 新增静态 DOM 文案：在元素上加 `data-i18n="中文"`（标题用 `data-i18n-title`）。
- 新增数据实体：在展示处用 `t(obj.name)` / `t(obj.desc)`；若直接渲染，全局写入钩子也会兜底翻译。
- 注意局部变量 `t` 会遮蔽翻译函数：循环 `TASKS.forEach(function (t) { ... })` 内如需翻译，改用 `isEn() ? 'English' : '中文'` 或重命名循环变量。
- 新增文案后建议跑一次「全量字符串残留检查」：对抽取的可见文本执行 `translateAny`，确认结果不含 `[\u4e00-\u9fa5]`。

## 6. 缓存与故障排查（v2.23.1）

曾出现「语言按钮可见但点击无效、整站仍是中文」：代码链路本身在干净环境测试通过，实际原因是运行目录里前端文件新旧混用——`dist/win-unpacked/resources/game` 与旧便携包中没有 `js/i18n.js`，或在预览壳里 `main.js` 被缓存成没有 `setlang` 分支的旧版本，而 `ui.js` 已刷新出语言按钮。

两层防护：

1. `tools/version.js` 在升版 / `sync` 时自动给 `index.html` 中所有本地 css/js 追加 `?v=<版本>`，强制整组文件随版本一起刷新，避免只更新一半文件。
2. `i18n.js` 自带语言按钮的 document 点击监听，不依赖 `main.js` 是否为新版。

排查顺序：确认页面版本号是否为当前版本 → 浏览器 DevTools Network 看 `main.js` 是否带最新 `?v=` → 确认 `js/i18n.js` 是否 200 → 若是打包程序，重新构建以刷新 `resources/game`。
