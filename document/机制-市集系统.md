# 机制 · 市集系统

> 相关代码：`js/data.js`（`SHOPS/shopPrice/findShop`）、`js/engine.js`（`buyItem/sellItem/sellPrice`）、`js/ui.js`（`renderShop`）、`js/main.js`（`shopcat/buy/buymax`）

市集参考《梅尔沃放置》的**多商店机制**：按分类分店铺采购，采用**加价购入、折价出售**的价格模型，形成灵石的回流与消耗。

---

## 1. 价格模型

| 方向 | 公式 |
| --- | --- |
| **购入价** | 若条目指定 `price` 用其值；否则 `floor(ITEMS[id].value × 1.8)` |
| **出售价** | `max(1, floor(value × 0.55 × (1 + formBonus('sell'))))` |

- **加价 1.8 倍购入 / 折价 0.55 倍出售**：买卖间存在价差，防止「买低卖高」套利，鼓励玩家自产自用。
- 聚宝阵「出售价」阵纹（每级 +2%，上限 +20%）可提高卖价。

`shopPrice(item)`：`item.price` 优先，其次按 `value × 1.8`。

## 3. 购入（`buyItem`）

```
buyItem(id, qty, price)
  1. 物品存在且 qty > 0
  2. 灵石 >= price × qty
  3. 背包可容纳（invCanAdd）
  → 扣灵石、invAdd、写日志
```

界面提供三种购买量：

| 操作 | `data-act` | 行为 |
| --- | --- | --- |
| 买 1 / 买 10 | `buy` | `buyItem(id, qty, price)` |
| 买最多 | `buymax` | `qty = floor(灵石 / price)`（价格 > 0 时） |

> 背包满时，购入「新种类」会被拒绝（`invCanAdd` 返回 false）。

## 4. 出售（`sellItem`）

- 与背包共用出售逻辑（见 [背包系统](./机制-背包系统.md)）。
- `sellItem(id, qty)`：`qty < 0` 表示全部出售。

## 5. 界面与交互

- **侧栏「🏪 市集」**：显示「采买 · 出售」摘要。
- **分类切换**：`ui.shopCat`（general / material / pill / equip），由 `shopcat` 事件切换。
- **店铺条目**：图标、名称、说明、单价、库存无上限；提供「买 1 / 买 10 / 买最多」按钮。
- **出售入口**：走背包的出售模式与 popover，不单独设店铺界面。

## 6. 经济循环

```
        ┌──────── 灵石 ────────┐
        │                      │
   采买资源/装备            出售冗余产物
        │                      │
        ▼                      ▲
   投入生产 / 增强战力 ──► 产出更值钱的物品
        │
        └── 突破境界消耗灵石 + 丹药
```

灵石来源：战斗击杀、熔炼提炼、出售物品、任务奖励。
灵石去向：市集采买、境界突破（跨境消耗）、装备获取。

---

## 7. 扩展指引

- 新增店铺：在 `SHOPS` 追加 `{ id, name, icon, items: [{id, price?}] }`。
- 新增上架物品：往对应店铺的 `items` 添加条目；如需统一定价，省略 `price` 让其按 `value × 1.8` 计算。
- 若引入「限购 / 补货」机制，需要在 `state` 增加库存字段并在 `mergeState` 迁移。
