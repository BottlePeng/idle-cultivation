# 机制 · 入世系统

> 参考《梅尔沃放置》盗窃（Thieving）机制设计：选择目标 → 概率判定成败 → 成功得报酬与掉落，失败被罚并眩晕。
> 在本作中改编为「红尘历练」：修士藏匿身份，混迹凡间百业体验生计。

---

## 1. 概述

入世是一个**占用动作槽**的主动技能：从职业列表中选择一种凡人生计开始体验，每个周期（约 3~4 秒）结算一次——

- **成功**：获得灵石报酬 + 概率掉落该职业特色物品 + 全额经验；
- **失败**：动作**立即中断**，被罚灵石（不超过持有量）、受到少量伤害、进入眩晕，经验减半。

技能名称显示为「入世」，内部 id 为 `thieving`。经验曲线：`need = 26 * lvl^1.45`（[技能与精通](./机制-技能与精通.md)）。

## 2. 与动作槽的关系

| 环节 | 行为 |
| --- | --- |
| 开始体验 | 占用动作槽（与其他技能互斥，点击其他条目会打断） |
| 每周期结束 | 概率判定成败；成功则**动作继续**自动循环 |
| 失败 | `completeActivity` 返回 false → 动作槽清空 + 进入眩晕 |
| 眩晕期间 | **无法开始任何新动作**（含战斗），眩晕在后台自然倒计时，离线同样推进 |

眩晕显示在顶部动作条：「😵 眩晕中 — 被识破后缓一缓，稍候自动恢复」。

设计取向：**档次越高的职业报酬与经验越高，但基础成功率越低、被罚越重**——期望收益仍随档次上升，风险同步放大。

## 4. 判定与结算公式

```
实际成功率 = min(0.95, 基础成功率 + 精通等级 × 0.002)     ← 每级精通 +0.2%，"越干越熟"
报酬灵石  = round(randInt(下限, 上限) × (1 + 聚宝阵 gold 加成))
掉落判定  = min(1, 物品概率 × (1 + 聚宝阵 drop 加成))      ← 每件掉落独立判定
双倍产出  = doubleChance(职业id, 'thieving')               ← 精通/技能等级/疾风阵通用通道
```

**失败结算**：`罚款 = min(当前灵石, fine)`；`生命 = max(1, 生命 - dmg)`；`眩晕 = stun 秒`；经验 = `round(经验 × 0.5)`。

> 生命保底 1 点：凡人伤不了修士性命，不会因入世失败死亡（也规避了离线快进中的死亡边界问题）。

## 5. 加成联动

| 来源 | 通道 | 效果 |
| --- | --- | --- |
| 大境界（[修炼与境界](./机制-修炼与境界.md)） | 通用 | 每大境界 +4% 动作速度、+6% 经验（`xpMul` 默认 gather 通道，受聚灵阵 `xp_gather` 加成） |
| 聚灵阵 | `xp_gather` | 入世经验加成 |
| 聚宝阵 | `gold` / `drop` | 报酬灵石与掉落概率加成 |
| 疾风阵 | `speed` / `double` / `mastery` | 动作提速、双倍产出、精通经验 |
| 精通（[技能与精通](./机制-技能与精通.md)） | 职业独立 | 每级 -0.2% 耗时（上限 -20%）、+0.5% 双倍产出，**本技能特有：+0.2% 成功率** |

## 6. 产出物品

| 物品 | 类型 | 价值 | 用途 |
| --- | --- | --- | --- |
| 🍚 米饭 | 食物 | 2 | 回复 12 生命（前期廉价口粮） |
| 🍶 浊酒 | 食物 | 5 | 回复 18 生命 |
| 🧶 麻布 | 材料 | 7 | 出售换取灵石 |
| 🖼️ 名家字画 | 材料 | 26 | 出售换取灵石 |

掉落同时复用现有物品（青鱼/灵鲤/矿石/灵草/种子/丹药），出售价与购入价遵循[市集系统](./机制-市集系统.md)的通用折价规则。

## 7. 实现位置

| 层 | 文件 | 内容 |
| --- | --- | --- |
| 数据 | `js/data.js` | `SKILLS.thieving`、`SKILL_ORDER`、`ACTIONS.thieving`、`ITEMS`（米饭/浊酒/麻布/名家字画） |
| 状态 | `js/state.js` | `state.stun`（眩晕剩余秒数），`mergeState` 兼容旧存档 |
| 引擎 | `js/engine.js` | `thievingCycle()`（成败判定）、`completeActivity` 分支、`passiveTick` 眩晕倒计时、`startAction`/`startCombat` 眩晕守卫 |
| 界面 | `js/ui.js` | `renderThieving()` 职业卡片、`currentBarHTML` 眩晕提示 |
| 入口 | `js/main.js` | 无需改动（`action`/`select` 事件分发为通用逻辑） |

侧栏入口位于「灵植」之后（`SKILL_ORDER` 末位）。

## 8. 扩展指引

新增职业只需在 `ACTIONS.thieving` 数组中追加一条配置：

```js
{ id: 'job_xxx', name: '职业名', icon: '🎭', req: 40, time: 4.0, xp: 180,
  rate: 0.60, gold: [120, 240], fine: 100, dmg: 12, stun: 4,
  loot: [{ id: '物品id', chance: 0.3, qty: 1 }] }
```

界面、精通、存档均自动适配，无需改其他层。
