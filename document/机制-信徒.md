# 机制 · 信徒（招募与上阵）

> 参考《梅尔沃放置》的宠物 / 召唤物设计，把「信徒」做成可装备的常驻加成位。
> 信徒不占用动作槽、不参与战斗，只提供被动加成，可随时上阵 / 卸下。

## 1. 解锁与容量

信徒系统由**洞天建筑「🏛️ 招贤殿」**解锁（秘境地形，门槛建设度 1，**开局即可营造**）。

首次营造只需 **700 灵石**（req ≤ 1 的资源建筑首建免木材/石料，从 Lv.2 起才需要材料）。

```
容量（含上阵） = 2 + 3 × (招贤殿等级 − 1)
上阵位数        = 招贤殿等级 × 1（未建造时为 0，信徒只能待在仓库）
```

| 招贤殿等级 | 容量 | 上阵位 | 可招最高品阶 |
| --- | --- | --- | --- |
| 未建造 | 0 | 0 | — |
| Lv.1 | 2 | 1 | 凡品 |
| Lv.2–3 | 5–8 | 2–3 | 灵品 |
| Lv.4–7 | 11–20 | 4–7 | 仙品 |
| Lv.8+ | 23+ | 8+ | 神品 |

容量是**总数**（仓库待命 + 上阵），上阵不额外占容量；上阵位则单独由招贤殿等级决定，每级 +1。

## 2. 招募

```
招募费 = floor(600 × 1.12^已有信徒总数)
```

- 花费灵石，招募到的信徒**按品阶权重随机**，且不会超过当前招贤殿允许的最高品阶。
- 品阶权重：凡品 55 / 灵品 30 / 仙品 12 / 神品 3（只在可招池内归一）。
- 招募到的信徒先进入「信徒仓库」，等待上阵。

| 品阶 | 颜色 | 单件加成量级 |
| --- | --- | --- |
| 凡品 | 绿 | 单属性 +3% |
| 灵品 | 蓝 | 单属性 +5%~6% |
| 仙品 | 紫 | 双属性，合计 +10%~16% |
| 神品 | 金 | 单/双属性 +12%~20% |

## 3. 上阵（视作装备）

- 上阵位数量 = **招贤殿等级**（每级 1 位，未建造时 0 位），与装备栏相互独立，加成**常驻生效**（离线结算同样计入）。
- 仓库中点击「装备」→ 自动占用第一个空位；点击已上阵格子 → 卸回仓库（**不受容量检查**，因为总数不变）。
- 同一位信徒可以招到多个副本，每个副本独立占一格。

## 4. 加成通道

信徒加成统一走 `discipleBonus(key)`（`js/engine.js`），返回小数，叠加口径与阵法 / 洞天一致：**同通道线性相加**。

| key | 含义 | 接入点 |
| --- | --- | --- |
| `speed_<技能ID>` | 该技能动作速度 | `actionSpeed(skillId)`（如 `speed_woodcutting`） |
| `speed` | 全局动作速度 | `speedMul()` / `actionSpeed()` |
| `speed_combat` | 战斗出手速度 | `calcStats().attackTime` |
| `atk` / `def` / `hit` / `ev` / `hp` | 战斗属性 | `calcStats()` |
| `xp` / `cultxp` | 全技能经验 / 打坐修为 | `xpMul()` |
| `gold` / `sell` | 灵石收益 / 出售价 | 各处灵石结算 / `sellPrice()` |
| `drop` | 掉落率 | `killMonster()` / `thievingCycle()` |
| `mastery` / `double` | 精通经验 / 额外产出概率 | `masteryGain()` / `doubleChance()` |
| `spirit` / `regen` | 灵力凝聚 / 脱战回血 | `passiveTick()` |

## 6. 存档结构

```js
state.disciples = {
  owned: ['d_wood', 'd_crane'],          // 仓库待命（按招募顺序）
  equipped: ['d_immortal', 'd_crane']   // 长度 = 招贤殿等级（此处为 Lv.2）
}
```

`mergeState()` 校验策略：

- 非法 / 已删除的 id 直接丢弃；
- 上阵位数组长度按存档中的招贤殿等级重建；降级时多出的位置上的信徒退回仓库；
- 若「仓库 + 上阵」超过当前招贤殿容量，从仓库末尾裁剪（上阵不受影响）。

## 7. 界面

侧栏「世界」下方新增「🙏 信徒」按钮，副标题显示「上阵 n/上阵位 · 仓库 m/容量」。
面板自上而下：状态条 → 招募按钮（动态显示费用 / 已满）→ 上阵格（数量 = 招贤殿等级，点击卸下）→ 仓库卡片网格（点击「装备」上阵）。
未建招贤殿时，面板只显示引导文案（前往「世界」→「秘境」→ 招贤殿，首建 700 灵石）。
