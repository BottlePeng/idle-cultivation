# 机制 · 生产技能

> 相关代码：`js/data.js`（`ITEMS/ACTIONS/RECIPES`）、`js/engine.js`（`startAction/cycleTick/completeActivity/findActivity/matsOk`）

生产技能分两类：

- **采集类**（`ACTIONS`，无消耗）：伐木、钓鱼、采矿、炼丹的「采药」子动作。
- **配方类**（`RECIPES`，有消耗）：炼器的熔炼 / 锻造、炼丹的丹方。

两类都遵循**单一动作槽**与**精通**规则，详见 [动作槽与离线收益](./机制-动作槽与离线收益.md) 与 [技能与精通](./机制-技能与精通.md)。

## 3. 动作完成结算（`completeActivity`）

### 3.1 配方类

1. 校验材料（`matsOk`）与背包可容纳；
2. **扣材料**；
3. 结算产出：物品（受额外产出翻倍）/ 灵石（受 `formBonus('gold')`）/ 灵力 / 修为；
4. `stats.crafts++`；`addXp(skill, def.xp)`；`addMastery(def.id, masteryGain(def))`。

### 3.2 采集类

1. 产出物品，`doubleChance(id, skill)` 概率翻倍；
2. `stats.gathered++`；
3. 采药额外 30% 掉种子；
4. `addXp(skill, def.xp)`；`addMastery(def.id, masteryGain(def))`。

### 3.3 缺材料 / 背包满

- 缺材料或背包满 → **原地等待**（`actionWaiting = true`），不中断动作；条件恢复自动继续。

## 4. 材料闭环

```
伐木 → 灵木/寒松木/铁木 ─┐
钓鱼 → 青鱼/灵鲤/龙须鱼 ─┤（食物）
采矿 → 铁矿石/玄铁矿/灵石原矿 ─┤
炼丹(采药) → 灵草/聚气草/疗伤草/筑基花/凝元参/化婴芝 ─┤
战斗掉落 → 兽皮/矿石/药材 ─┤
灵植(收获) → 药材 ─────────┘
                     │
       ┌─────────────┴─────────────┐
       ▼                           ▼
   炼器：熔炼→锭 → 锻造→装备      炼丹：丹方→丹药
       │                           │
       ▼                           ▼
   战斗属性提升                修为/疗伤/突破
```

## 6. 扩展指引

- 新增采集点 / 配方：直接追加到 `ACTIONS` / `RECIPES` 对应技能数组。
- 新增材料：在 `ITEMS` 追加条目，`type: material`。
- 炼器面板按 `cat` 分组渲染（熔炼 / 锻造）；炼丹按 `pill` 分组。
