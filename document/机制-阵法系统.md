# 机制 · 阵法系统

> 相关代码：`js/data.js`（`FORMATIONS/formCost/findFormation`）、`js/engine.js`（`formBonus/formUpgrade/formState`）、`js/main.js`（`formup` 事件）

阵法参考《梅尔沃放置》的**观星 / 星座系统**：通过「观星台」推演天机获得 **星砂**，再以星砂**点亮阵纹**，换取常驻的全局加成。

---

## 1. 两大环节

```
观星台（采集类动作）──► 💫 星砂 ──► 点亮阵纹 ──► 常驻全局加成
```

1. **观星**：阵法的采集类动作，产出星砂（**不占背包**，直接计入资源）。
2. **点亮阵纹**：消耗星砂提升某条阵纹等级，永久提供百分比加成。

> 每条阵纹的加成均为**每级**百分比，等级上限统一 **10 级**（`mods[].max`）。

### 3.1 阵纹通道（`mods[].key`）

阵法只为其他系统提供**加成通道**，本身不消耗。引擎通过 `formBonus(key)` 汇总所有阵法的同类加成：

| key | 作用对象 | 消费方 |
| --- | --- | --- |
| `speed` | 动作周期推进 | `speedMul` |
| `double` | 物品额外产出 | `doubleChance` |
| `mastery` | 精通经验 | `masteryGain` / 战斗精通 |
| `growth` | 灵植生长速度 | `growPlots` |
| `xp_cult` / `xp_gather` / `xp_combat` / `xp_craft` | 各技能经验（按 `XP_GROUP`） | `xpMul` |
| `gold` / `drop` / `sell` | 灵石 / 掉落 / 出售价 | 战斗结算、市集 |
| `hp` / `def` / `regen` | 生命 / 防御 / 脱战回血 | `calcStats`、被动回血 |
| `atk` / `hit` / `ev` | 攻 / 命 / 闪 | `calcStats` |
| `spirit` | 灵力自然凝聚 | `passiveTick` |

---

## 4. 加成汇总（`formBonus`）

```js
formBonus(key)
  = Σ（遍历所有阵法 × 其阵纹）
    若 m.key === key：加上 min(m.max, 阵纹等级) × m.per
```

- **同类叠加**：多个阵法若有同名 key，加成累加（如聚灵阵与太虚阵都提供 `xp_cult`）。
- 阵纹等级非负、且钳制到 `max`。

---

## 5. 点亮阵纹（`formUpgrade`）

```
cost = floor(基础消耗 × 成长^当前等级 × (1 + 阵纹序号 × 0.35))
```

校验顺序：

1. 阵法存在且 `modIndex` 合法；
2. 阵法技能等级 ≥ 阵法 `req`；
3. 阵纹未满级（< `max`）；
4. 星砂 ≥ `cost`。

通过后：扣星砂、阵纹等级 +1、写入日志。

> **成长指数**（1.40~1.50）使后期点亮成本快速上升，形成长线消耗星砂的循环。

---

## 6. 与技能经验的联动（`XP_GROUP`）

引擎按技能分组读取阵法经验加成：

| 组 | 技能 |
| --- | --- |
| `cult` | 修炼 |
| `combat` | 战斗 |
| `craft` | 炼器、炼丹 |
| `gather` | 伐木、钓鱼、采矿、**灵植**以及默认其他 |

- **阵法自身不吃任何阵法经验加成**（避免自循环加速）。

---

## 7. UI 表现

- **侧栏「🧭 阵法」**：等级与经验。
- **顶栏**：解锁观星后显示 💫 星砂（开局不显示，避免冗余）。
- **阵法面板**：阵法卡片（图标、门槛、说明）+ 各阵纹行（当前等级、加成值、点亮消耗星砂、按钮），按钮在星砂不足或未解锁时置灰。
- 星砂数量与按钮可用性走 `updateFormState()` 增量刷新。

---

## 8. 扩展指引

新增阵法：

1. 在 `FORMATIONS` 追加条目，定义 `req/cost/growth/mods`。
2. 若引入新加成通道 `key`，在对应系统（如 `calcStats`、`passiveTick`、`doubleChance`）读取 `formBonus(key)`。
3. `mergeState` 会自动按当前 `FORMATIONS` 裁剪旧存档的阵纹等级。
