# 机制 · 提醒视觉

> 版本：v2.19.0 ｜ 对应代码：`js/ui.js`（`sidebarEntryMeta` / `sidebarEntryHTML` / `renderSidebar`）、`css/style.css`（提醒视觉分级）

## 1. 目标

让「有东西可点」在侧栏与面板中一眼可见，同时不让日常状态和必须处理的状态混成一片：

- 可领取 / 阻塞类提醒明显强于普通说明；
- 教学类（可选）提醒保持低调，不参与脉冲；
- 动效克制：只做小面积脉冲，只改 `transform` / `opacity`；
- 不新增常驻状态，不干扰 `setHTML` 签名去重与 `data-*` 增量刷新。

## 2. 四档层级

| 档位 | 触发场景 | 视觉 | 动效 |
| --- | --- | --- | --- |
| `hot` | 任务有可领取、签到今日可领、锁妖塔待领奖、战阵有奖励待入库 | 金橙渐变徽标（数字或 `!`）、入口左侧橙色竖线、分组头橙点 | 2.4s 细脉冲环，持续轻微呼吸 |
| `block` | 异界裂缝未修复 / 裂缝怪物存活（穿越被阻塞） | 珊瑚红渐变徽标，入口左侧橙线 | 2.4s 细脉冲环 |
| `soft` | 问道未完成且未跳过（教学，可选） | 静态蓝徽标，入口左侧蓝色细线 | **不脉冲** |
| `busy` | 某动作正在进行 | 沿用原有 `.dot` 静态绿点 | 无 |

`busy` 不升级为闪烁：它只表示「正在做」，不代表「需要处理」。

## 3. 触达位置

| 位置 | 元素 | 说明 |
| --- | --- | --- |
| 侧栏入口 | `.skillbtn .badge.hot / .block / .soft` | 数字（任务数、战阵待入库数）或 `!`，18px 胶囊 |
| 入口底色 | `.skillbtn.has-alert.hot / .soft` | 左侧 2px 竖线 + 边框染色；当前选中（`.on`）保留原选中色 |
| 分组头 | `.sbgdot.hot / .soft` | 组内有 `hot` 时为橙点 + 脉冲，只有 `soft` 时为静态蓝点 |
| 折叠窥视 | `.sbpi.hasalert` | 图标右上角小圆点，不展开也知道哪个入口有提醒 |
| 窄屏图标模式 | `.skillbtn.has-alert::after`（≤1080px） | `sinfo` 隐藏后，在按钮右上角补点，`hot` 轻微缩放，`soft` 静态 |
| 面板提示条 | `.dynnote.warn` / `.shopnote.warnline` | 珊瑚色边框 + 左侧竖条 + `🔔`，与普通说明条（虚线）区分 |
| 任务面板 | `.taskentry.ready` | 可领取条目金色边框 + 底色 + 静态内发光，列表内不做动画 |
| 签到面板 | `.cknote.ready` | 今日可领提示做成金色胶囊 + `🎁` |

## 4. 实现约定

- **状态来源**：全部由 `sidebarEntryMeta(id)` 现算（任务未领数、签到状态、问道进度、裂缝/怪物、锁妖塔待领、战阵待入库），不写入存档。
- **渲染通道**：只改 `sidebarEntryHTML` / `renderSidebar` 生成的类名与徽标 HTML，仍走 `setHTML('#sidebar', html)` 签名去重；没有新增会被重绘覆盖的 DOM 状态。
- **动效**：`alertRing` 仅作用于徽标 / 组头点的伪元素，`transform: scale()` + `opacity`，2.4s 一次；`alertDot` 只用于窄屏图标模式的小点。不使用位移，避免撑大滚动区。
- **图标**：只使用 Win10 可显示的 emoji（Unicode 6.0~12.0），本次新增 `🔔`（U+1F514）与 `🎁`（U+1F381）。
- **减少动态效果**：`@media (prefers-reduced-motion: reduce)` 下关闭全部提醒脉冲，只保留静态颜色与描边。

## 5. 层级边界

- 同一时间大量入口同时可领属于正常状态，但只有「可领取 / 阻塞」才脉冲；问道等教学内容固定为蓝色静态。
- 面板内列表（任务、签到天数）不做循环动画，只用颜色与描边提升权重。
- 新增提醒时先判断档位：**不处理会卡住进度 → `hot`/`block`；只是建议 → `soft`；正在运行 → `busy`**。

## 6. 扩展方式

1. 在 `sidebarEntryMeta` 对应分支返回 `alert: true` 与 `alertTier: 'hot' | 'block' | 'soft'`，并在 `sub` 中插入 `<span class="badge 档位">数字或 !</span>`。
2. 面板内需要强调的行加 `warn` / `warnline` / `ready` 类即可复用现有样式。
3. 新增档位时同步更新 `sidebarEntryHTML` 的 `has-alert` 类与 CSS，不要直接在业务代码里写内联动画。
