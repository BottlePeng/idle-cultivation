# 机制 · 五行属性裂缝（ELEM_RIFT）

> 版本：v2.3.0 ｜ 对应代码：`js/data.js`（`ELEM_RIFT`）、`js/state.js`（`elemRifts`）、`js/engine.js`（`elemRift*`）、`js/ui.js`（`renderElemRift / updateElemRift`）、`js/main.js`
>
> 本文只描述「五行属性裂缝」。它与 [异界裂缝](./机制-异界裂缝.md) 是**两个独立系统**：不进穿越门槛、不写 `state.rift`、不影响穿越按钮。

---

## 1. 定位

| 项 | 内容 |
| --- | --- |
| 入口 | 穿越星球面板 → 「五行属性裂缝」区域（3 张卡片） |
| 定位 | 周期性材料副本：花一次战斗换当前档材料，服务伐木 / 钓鱼 / 炼器 / 炼丹 / 阵法 |
| 与异界裂缝 | 并行独立；异界裂缝卡穿越次数，五行裂缝只发材料 |
| 与穿越 | **不参与门槛**：五行裂缝未修复时仍可正常穿越 |
| 动作槽 | 占用全局唯一动作槽，与星球运转 / 锁妖塔 / 异界裂缝 / 普通战斗互斥 |

## 3. 刷新机制

```
生成（新档 / 旧档兜底 / 到期）→ 3 道随机属性裂缝 + next = now + 3h
        │
        ├─ 修复一道 → 该位置 fixed=true，留空到下一轮
        │
        └─ Date.now() ≥ next → 整轮覆盖：重新随机 3 道，fixed 全部复位，next = now + 3h
```

- **计时基准是真实时间** `Date.now()`，不是动作计时，也不走离线结算。
- **不做离线补刷**：离线超过 3 小时回来，只刷新**一轮**（`next` 直接设为当前时间 +3h），不会按离线小时数连刷。
- **战斗中推迟**：若到期瞬间正在修复某道属性裂缝，则推迟到本次战斗结束后再刷新，避免槽位在战斗中被换掉。
- 刷新是**覆盖式**：新 3 道直接替换旧的 3 道，不存在排队或堆积。

## 4. 强度公式

### 4.1 强度层级 t（生成时快照）

```
t = clamp(round(穿越次数 × 2.2 + (对应工作等级 − 1) × 0.4), 0, 10000)
```

- `t` 在**生成那一刻**按当时的工作等级与穿越次数算好并存进槽位，之后升级不会让已在场的裂缝临时变难；下一轮刷新才吃新等级。
- 两个来源都计入：工作等级越高越难（避免高等级玩家白拿高档材料），穿越次数越高越难（与异界裂缝的压力同步）。

### 4.2 妖物属性（`elemEnemy`）

```
生命 = round(30 × (1 + 0.26t + 0.007 × t^1.6))
攻击 = 2 ~ 4 × (1 + 0.14t + 0.003 × t^1.45)
命中 = 7 + 0.9t
闪避 = 4 + 0.55t
减伤 = min(30%, 1% + 0.1%t)
出手间隔 = max(2.0s, 3.0 − 0.0012t)
```

| t | 生命 | 命中 | 闪避 | 减伤 | 出手间隔 |
| --- | --- | --- | --- | --- | --- |
| 0 | 30 | 7 | 4 | 1% | 3.00s |
| 5 | 72 | 12 | 7 | 2% | 2.99s |
| 20 | 211 | 25 | 15 | 3% | 2.98s |
| 50 | 530 | 52 | 32 | 6% | 2.94s |
| 100 | 1143 | 97 | 59 | 11% | 2.88s |
| 149 | 1822 | 141 | 86 | 16% | 2.82s |

> 攻击显示值还受 4.3 的单次伤害上限约束，因此低血量玩家看到的攻击区间会被压平——这是保护，不是数值不变。

### 4.3 单次伤害上限（防一刀秒）

```
cap = round(玩家当前生命上限 × 0.16)
atkMax = min(atkMax, cap)；若 atkMin > cap 则 atkMin = round(cap × 0.55)
```

沿用异界裂缝的思路：任何层级下单次伤害不超过玩家生命上限的 16%。实测 Lv.1（60 生命）对 `t = 2200`，`atkMax = 10 = round(60 × 0.16)`。

### 4.4 低等级可打 / 高等级有压力

- 新档全技能 Lv.1、穿越 0 次 → `t = 0`：生命 30、攻击 2~4、命中 7，Lv.1 玩家（60 生命）实测 14~38s 通关，20 场 0 阵亡，最低剩余 41/60。
- 工作等级 99、穿越 50 次 → `t = 149`：生命 1822，命中 141（对 Lv.1 玩家近乎必中），但单次伤害仍被 16% 上限锁死，不会秒杀。

## 5. 修复奖励

按**对应工作当前等级**选档：取「该等级已解锁的最高档」产出，未解锁任何档时退化到最低档；数量 `1 + floor((等级−1)/20)`，上限 5。

| 属性 | 奖励来源 | 选档方式 | 当前档示例 |
| --- | --- | --- | --- |
| 木 | 伐木产出 | `ACTIONS.woodcutting` 中 `req ≤ 等级` 的最高档 | Lv.1 灵木 ×1；Lv.55 灵虚木 ×3；Lv.99 混沌木 ×5 |
| 水 | 钓鱼产出 | `ACTIONS.fishing` 中 `req ≤ 等级` 的最高档 | Lv.1 青鱼 ×1；Lv.55 须鱼王 ×3；Lv.99 混沌鱼 ×5 |
| 火 | 炼丹可用药材 | `RECIPES.alchemy` 中 `req ≤ 等级` 的最高档丹方的**主药材** | Lv.1 聚气草 ×1；Lv.55 化婴芝 ×3；Lv.99 无虚根 ×5 |
| 金 | 炼器输入材料 | `RECIPES.smelting` 中「矿石 → 同名锭」配方里 `req ≤ 等级` 的最高档**矿石** | Lv.1 铁矿石 ×1；Lv.55 神玉 ×3；Lv.99 混沌石 ×5 |
| 土 | 星砂 | 阵法没有物品形态的输入材料，星砂是阵法唯一消耗品 | Lv.1 星砂 ×1；Lv.55 星砂 ×3；Lv.99 星砂 ×5 |

设计说明：

- **金只给输入材料，不给炼器产物**：`sm_iron`（铁矿石 → 铁锭）这类「矿石 → 同名锭」的正规熔炼配方才纳入选档，避开铁木汁、灵石提炼等特殊配方；奖励发矿石，符合「炼器所需材料」。
- **土发星砂**：阵法体系只有 `formations[].levels` 这一种消耗（星砂），没有可发放的「阵法材料」物品；发星砂等价于给阵法进度的直接材料。
- 数量 1~5 随等级提升；高等级直接给高档材料，不会发已经用不上的低档货。
- 奖励在**开战瞬间**快照（物品与数量），战斗中使用该快照，避免战斗中途升级导致奖励漂移。
- **背包已满**：开战前检查；开战时背包满则拒绝进入并提示；击杀结算时若背包已满，则**不修复**并提示清理背包后可重试，避免材料凭空消失。

## 6. 战斗与动作槽

- `state.action = { skill: 'elem', id: '<槽位下标>' }`；`state.skills.combat.elem = 下标`，`target.id = '__elem__'`。
- 完全复用 `combatTick` 的命中 / 闪避 / 减伤 / 伤害浮动 / 出手节奏；只是「一只目标、击杀不刷新、不循环」。
- 开始修复会：`planetInterrupt()` + `cancelCombat()`，然后占用动作槽。
- 切换任意其它动作（伐木、打坐、星球、锁妖塔、异界裂缝、普通战斗）都会 `cancelCombat()`，把 `combat.elem` 置 −1、`elemRw` 清空，无残留目标。
- 阵亡：只退出战斗，槽位 `fixed` 保持 `false`，`tier` 不变，不消耗、不降级，回血后可原地重试。
- 动作条：`currentProgress()` 对 `elem` 返回 `1 − target.hp / target.maxHp`，可正常走到 100%。

## 7. 存档

### 7.1 字段

```js
state.elemRifts = {
  next: 1730000000000,          // 下次整轮刷新的时间戳（Date.now）
  slots: [                       // 固定 3 个
    { elem: 'metal', tier: 12, fixed: false },
    { elem: 'fire',  tier: 3,  fixed: true  },
    { elem: 'wood',  tier: 0,  fixed: false }
  ]
}
```

- `elem`：五行 id；`tier`：生成时强度快照；`fixed`：是否已修复（修复后位置留空）。
- `state.skills.combat.elem / elemRw` 是**战斗瞬态**，不参与持久语义。

### 7.2 读档规则

| 情况 | 处理 |
| --- | --- |
| 有合法 3 个 slot | 恢复属性 / 强度 / 已修复状态 |
| 旧档无 `elemRifts` 字段 | 按当前时间**立刻生成一轮新的三个**（不白送已修复） |
| slot 数量不足或非法 | 丢弃非法项后补足；`elem` 非法则重掷 |
| `next` 缺失 / 非法 | 现在 + 3 小时 |
| `next` 已过期 | 立刻整轮刷新（离线不补刷，只刷一次） |
| 读档时正在打属性裂缝 | 不恢复战斗：`action=null`、`combat.elem=-1`、`target=null`，但槽位 `fixed` 状态原样保留 |

## 9. 设计取舍与风险

- **3 道允许重复**：5 选 3 允许重复更符合「随机裂缝」的观感，实现也更简单；若强制不重复，则每轮必然是 3 种不同属性，长期看反而更单调。重复时玩家可在下一轮等刷新。
- **强度快照而非实时**：避免玩家在裂缝在场期间升级反而「打不过自己变难的裂缝」；下一轮会按新等级提升，成长仍有压力。
- **攻击上限按当前生命**：高等级玩家生命高，上限随之提高，攻击成长可见；低血量玩家被保护，不会被一刀秒。
- **风险**：土行只有星砂，若后续加入阵法材料物品，应同步改成物品奖励并更新本文档。
