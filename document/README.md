# 仙途挂机 · 设计文档

本目录收录《仙途挂机 · Idle Cultivation》的策划与系统设计文档。

- 玩法参考：《梅尔沃放置》(Melvor Idle) 的动作 / 精通 / 命中制战斗 / 多商店 / 观星 / 种植；《凡人修仙传》的境界 / 灵根 / 丹药体系。
- 技术约束：纯静态网页 · 零外部素材 · 无构建步骤 · 双击 `index.html` 即可运行 · 支持离线。
