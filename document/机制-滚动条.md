# 机制 · 全局滚动条

> 版本：v2.18.0 ｜ 对应代码：`css/style.css`（全局 `::-webkit-scrollbar` 规则）、`js/main.js`（`initScrollFade` / `markScrolling`）

## 1. 目标

统一整个游戏的滚动条视觉与行为：

- 宽度变窄（桌面 6px、窄屏 4px）；
- 没有滚动时隐藏；
- 滚动进行中、鼠标悬停时可见；
- 停手后延迟淡出，而不是瞬间消失；
- 覆盖所有滚动容器，避免部分区域仍是粗滚动条；
- 不引入库，不与 `tick` / `setHTML` 签名去重 / `updateBars` 增量刷新互相干扰。

## 2. 覆盖范围

全局规则直接作用于 `::-webkit-scrollbar`，因此以下容器全部生效，无需逐个添加 class：

| 容器 | 滚动方向 |
| --- | --- |
| `#content`（主内容区） | 竖向 |
| `#sidebar`（侧栏；≤820px 时横向） | 竖向 / 横向 |
| `#right`（右侧信息栏） | 竖向 |
| `#logList` / `.dblog`（见闻 / 战报） | 竖向 |
| `.scroll`（通用滚动容器，`#content` / `#right` / `#logList` 均使用） | 竖向 |
| `.confirmbox`（应用内确认弹窗） | 竖向 |
| `body` / `main`（≤820px 移动布局） | 横向 / 竖向 |
| 后续新增的任何 `overflow: auto/scroll` 容器 | 自动继承 |

## 3. 视觉规格

```css
::-webkit-scrollbar { width: 6px; height: 6px; }
::-webkit-scrollbar-track,
::-webkit-scrollbar-corner { background: transparent; }

::-webkit-scrollbar-thumb {
  min-height: 28px;
  border-radius: 999px;
  border: 1px solid transparent;   /* 让可见滑块再窄 2px */
  background-clip: padding-box;
  background-color: rgba(216, 178, 106, 0);   /* 默认透明 = 隐藏 */
  transition: background-color .45s ease;     /* 淡入 / 淡出 */
}
```

- 默认：滑块完全透明，只保留 6px 的滚动条槽位，因此显隐不会引起内容宽度跳动。
- 悬停容器：`X:hover::-webkit-scrollbar-thumb` 变为 `rgba(216,178,106,.42)`。
- 滚动中：容器带 `.is-scrolling` 时同样显示。
- 直接悬停滑块：加深到 `rgba(216,178,106,.62)`。
- 窄屏（≤820px）：宽 / 高降为 4px。

## 4. 滚动中的显示与延迟淡出

CSS 无法感知「正在滚动」，因此用一段极轻量的 JS：

```js
const _scrollFade = { active: new WeakSet(), timers: new WeakMap() };

function markScrolling(el) {
  if (!_scrollFade.active.has(el)) {
    _scrollFade.active.add(el);
    el.classList.add('is-scrolling');
  }
  clearTimeout(_scrollFade.timers.get(el));
  _scrollFade.timers.set(el, setTimeout(function () {
    _scrollFade.active.delete(el);
    _scrollFade.timers.delete(el);
    el.classList.remove('is-scrolling');
  }, 900));
}
```

- 只注册 **一个** `document` 捕获阶段 `scroll` 监听（`{ capture: true, passive: true }`）；`scroll` 不冒泡，但捕获阶段可以覆盖所有后代容器。
- 不给每个滚动容器单独绑定，也不保存任何渲染状态。
- `WeakSet` / `WeakMap` 保证容器被重建（`setHTML` 整树重绘）后不会泄漏。
- 停手 900ms 后移除 `.is-scrolling`，再由 CSS 的 0.45s transition 完成淡出。
- 鼠标仍停在容器上时，`:hover` 会让滑块保持可见；移开后按上述延迟淡出。

## 5. 触摸 / 窄屏

- 触摸设备没有 hover，滑块只在滚动时出现，停手后淡出。
- ≤820px 时滚动条降为 4px，侧栏横向滚动的条高同样是 4px。
- 滚动条槽位始终保留，不产生横向溢出，也不会在显隐时挤压布局。

## 6. 取舍

- **不使用 `scrollbar-width` / `scrollbar-color`**：按需求使用 `::-webkit-scrollbar` 系列，Electron / Chromium 下可精确控制宽度与圆角。
- **不做完全 overlay 滚动条**：保留 6px / 4px 槽位，避免内容在滑块出现时横向抖动；隐藏仅指滑块透明。
- **不监听 `scrollend`**：用 900ms 定时器兼容性更好，也能覆盖连续滚动的每一帧。
- **不改动业务渲染**：`.is-scrolling` 只作用于滚动条伪元素，不影响 `setHTML` 签名、`data-bar` 或 `updateBars`。
