# 机制 · 灵植系统

> 相关代码：`js/data.js`（`FARM_SEEDS/FARMING_PLOT_REQS/findSeed/plotUnlocked`）、`js/engine.js`（`growPlots/plantSeed/harvestPlot`）、`js/ui.js`（`renderFarming/updatePlotGrowth`）、`js/main.js`（`farmseed/plot_plant/plot_harvest`）

灵植参考《梅尔沃放置》的**种植 / 园艺系统**，是本作**第一个打破「单一动作槽」范式**的机制：

- **种植 / 收获**是即点即结算的短暂操作，占用动作槽并给经验与精通；
- **生长**是后台被动过程，放进 `passiveTick` 推进，**不占槽**，因此**离线同样有效**。

---

## 1. 核心循环

```
种子 ──plantSeed──► 地块进入生长 ──passiveTick.growPlots──► 成熟(ready)
                                                              │
                                                   harvestPlot ▼
                                                         产出药材 + 经验 + 精通
```

### 1.1 种子来源

1. **市集购入**：水丹药阁 / 杂货铺等（见 [市集系统](./机制-市集系统.md)）。
2. **炼丹采药掉落**：每次「采药」动作有 **30%** 概率额外掉落该药材对应的种子（花时间换种子，梅尔沃式设计）。

## 3. 地块解锁（`FARMING_PLOT_REQS`）

共 **8 块**地块，随灵植等级逐步解锁：

| 地块序号 | 需要灵植等级 |
| --- | --- |
| 1 / 2 / 3 | Lv.1 |
| 4 | Lv.3 |
| 5 | Lv.6 |
| 6 | Lv.10 |
| 7 | Lv.15 |
| 8 | Lv.22 |

```
plotUnlocked(farmingLvl, idx) = idx < 8 && farmingLvl >= FARMING_PLOT_REQS[idx]
```

- 未解锁地块显示 🔒 与所需等级。

---

## 4. 数据模型

`state.plots` 为长度 8 的数组，每项：

```js
{ seedId: string | null, growth: 秒数, ready: boolean }
```

- `seedId = null` 表示空地。
- `growth` 累计生长秒数，`ready` 表示已成熟。

---

## 5. 种植（`plantSeed`）

校验顺序：

1. 地块已解锁（`plotUnlocked`）；
2. 种子存在（`findSeed`）；
3. 灵植等级 ≥ 种子 `req`；
4. 背包持有该种子 ≥1；
5. 地块为空。

通过后：

- 扣 1 枚种子；
- 地块置 `{ seedId, growth: 0, ready: false }`；
- **灵植经验** `addXp('farming', 生长时间 × 0.4)`；
- **精通** `addMastery('farm_plant', round(生长时间 × 0.3))`。

---

## 6. 被动生长（`growPlots`，在 `passiveTick` 中）

```js
mul = 1 + formBonus('growth')            // 疾风阵「灵植生长」加成
for (每块地块) {
  若 未种 或 已成熟 → 跳过
  growth += dt × mul
  若 growth >= seed.growTime → growth = growTime, ready = true
}
```

- 使用全局 `dt`，因此**离线模拟（`simulateOffline` 循环调用 `tick`）同样推进生长**。
- 「灵植生长」阵纹每级 +4%（疾风阵，上限 10 级 → 最多 +40%）。

---

## 7. 收获（`harvestPlot`）

校验：地块已解锁、已种、已成熟。

结算：

- 产出 `seed.outId × seed.yield`，受 `doubleChance` 概率翻倍（标注「精通·双倍」）；
- 清空地块（`seedId = null`）；
- **灵植经验** `addXp('farming', 生长时间 × 0.6)`；
- **精通** `addMastery('farm_harvest', round(生长时间 × 0.4))`。

---

## 8. 存档迁移

`mergeState` 对 `plots`：

- 按当前 `FARMING_PLOT_REQS.length` **裁剪长度**（超界丢弃）；
- 若 `seedId` 在当前 `FARM_SEEDS` 中找不到 → **清空地块**（防止旧存档引用已下线的种子）；
- `growth` 钳制为非负。

## 9. UI 表现

### 9.1 面板结构（`renderFarming`）

1. **种子选择条**：列出灵植等级够用的种子 chips，显示持有数量与单株时长；持有为 0 时置灰；选中的 chip 高亮（`state.ui.farmSeedId`）。
2. **灵田网格**：8 个地块卡，四种状态：
   - 未解锁：🔒 + 所需等级；
   - 空地：➕「选种后点此地块种下」；
   - 生长中：种子图标 + 进度条 + 「N 秒后成熟」；
   - 可收获：绿色呼吸光效 + 「点击收获」。
3. 提示文案：生长在后台自动推进、离线同样有效。

### 9.2 增量刷新（`updatePlotGrowth`）

- 生长进度条用 `data-plot="index"` 占位节点，由 `updatePlotGrowth()` 每 100ms 更新宽度。
- **不写进面板 HTML**，避免 `setHTML` 签名（剔除 `width:NN%`）导致的「进度条冻住」问题。

---

## 10. 测试要点（无头冒烟）

- 种子物品已创建；`findSeed` 可查。
- 种植消耗种子、地块进入生长。
- `growPlots` 推进至 `ready`；离线 `simulateOffline` 亦可成熟。
- 收获产出药材、地块清空；`farm_plant` / `farm_harvest` 精通产生。
- 存档往返后 `plots` 保留；`mergeState` 正确裁剪。
- 疾风阵 `growth` 加成生效（`formBonus('growth')` 随阵纹等级增加）。

---

## 11. 扩展指引

- 新增种子：在 `FARM_SEEDS` 追加（含 `outId`、`dropBy`），并在 `ITEMS` 定义对应 `seed_*` 物品。
- 新增地块：扩展 `FARMING_PLOT_REQS` 数组即可（`state.plots` 默认长度自动跟随）。
- 若要新增「加速道具 / 浇水」等交互，建议仍走 `passiveTick` 加速倍率，而非引入新的时间源。
