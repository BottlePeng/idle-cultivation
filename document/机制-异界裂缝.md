# 机制 · 异界裂缝

> 版本：v2.2.0 ｜ 代码入口：`RIFT` / `state.rift` / `startRift` / `riftCleared` / `renderRift`
>
> 异界裂缝是「穿越星球」的门槛战：每次穿越成功后生成一道裂缝，击败裂缝中的妖物（修复）后才能进行下一次穿越。它复用现有 `combatTick` 的命中 / 闪避 / 减伤 / 出手节奏与战败逻辑，不另建战斗引擎；占用全局唯一动作槽，不产生离线收益。

---

## 1. 定位与入口

- **入口**：穿越星球面板内的「异界裂缝」卡片，位于朝代 / 穿越控制区下方。点击切换到裂缝战斗视图（仍在穿越星球面板内），视图内可随时「返回星球」。
- **新档**：第一次进入游戏自带一道未修复裂缝（`tier = 0`），必须先修复才能完成第 1 次穿越。
- **生成时机**：每次 `planetCross()` 成功后立刻生成下一道裂缝，`tier = 新的穿越次数`。
- **核心循环**：

```
穿越成功 → 生成裂缝（open = true, tier = 穿越次数）
   ├─ 未修复：穿越按钮置灰，提示「需先修复异界裂缝」
   └─ 点击裂缝 → 进入裂缝战斗（占用动作槽）
          ├─ 击败 → 立刻发奖，open = false（已修复），动作槽释放
          │      └─ 返回星球 → 穿越按钮恢复 → 穿越成功 → 生成下一道裂缝
          └─ 阵亡 → 裂缝保持未修复，不扣穿越次数、不清空层级；回血后可原地重试
```

- **不惩罚**：裂缝阵亡只退出本次战斗，穿越次数、裂缝层级、裂缝未修复状态全部保留。

## 2. 裂缝强度

设 `t = tier`（生成时的穿越次数，新档为 0）：

| 属性 | 公式 | 说明 |
| --- | --- | --- |
| 生命 | `round(34 × (1 + 0.25t + 0.008 × t^1.7))` | 线性为主 + 轻幂律，早期约 20~30 秒 |
| 攻击 | `2~4 × (1 + 0.15t + 0.004 × t^1.5)` | 低于生命成长；另有单次伤害安全上限 |
| 命中 | `8 + 0.9t` | 与玩家闪避同步线性 |
| 闪避 | `5 + 0.6t` | 玩家命中率维持在 50%~95% |
| 减伤 | `min(0.30, 0.01 + 0.0012t)` | 上限 30%，不压低玩家输出 |
| 出手间隔 | `max(2.0, 3.2 - 0.0015t)` | 下限 2.0 秒，防止后期高频连击 |
| 单次伤害安全上限 | `min(攻击, round(玩家当前生命上限 × 0.18))` | 保证后期不会被一刀秒 |

**代表性层级**（无装备、无阵法、无境界加成的基准玩家预览；高层攻击受安全上限保护）：

| tier | 生命 | 攻击 | 命中 | 闪避 | 减伤 | 出手间隔 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | 34 | 2~4 | 8 | 5 | 1% | 3.20s |
| 1 | 43 | 2~5 | 9 | 6 | 1.1% | 3.20s |
| 10 | 133 | 5~11 | 17 | 11 | 2.2% | 3.19s |
| 50 | 669 | 20~40 | 53 | 35 | 7.0% | 3.13s |
| 100 | 1,567 | 40~80 | 98 | 65 | 13.0% | 3.05s |
| 1000 | 42,777 | 555~1110（Lv2000 基准） | 908 | 605 | 30.0% | 2.00s |

**平衡要点**：

- 第 0 层面向新档 Lv1 玩家：500 次实机模拟平均 24.2 秒、最长 45.6 秒，全部获胜，最低剩余生命 36/60（承伤约 6~24 点），不会在第 1 次就打死玩家。
- 第 1 层（穿越 1 次后）同为新档 Lv1：500 次模拟全部获胜，平均 31.4 秒、最长 50.4 秒，最低剩余生命 17/60，仍可通过，但已能感到压力。
- 玩家成长来自战斗等级、装备、境界、阵法、洞天 / 信徒等现有系统；裂缝修复奖励额外给战斗经验，帮助战斗等级跟进层级。
- `HIT_CAP = 0.18` 是硬安全阀：即使玩家严重落后于层级，单次承伤也不超过自身生命上限的 18%，不会被一刀秒；打不过时应先练战斗 / 补装备 / 提境界，而不是被永久锁死。

## 3. 奖励

修复后**立刻发放**，不需要二次领取（与锁妖塔的「先领奖再进层」不同）：

| 奖励 | 公式 |
| --- | --- |
| 灵石 | `round(10 × (t+1)^1.15) × (1 + formBonus('gold') + worldBonus('gold'))` |
| 星砂 | `max(1, round(1 × (t+1)^0.7))` |
| 战斗经验 | `round(16 × (t+1)^1.55)`，走 `addXp('combat')`，正常吃经验加成 |

| tier | 灵石 | 星砂 | 战斗经验 |
| ---: | ---: | ---: | ---: |
| 0 | 10 | 1 | 16 |
| 1 | 22 | 2 | 47 |
| 10 | 158 | 5 | 658 |
| 50 | 920 | 16 | 7,093 |
| 100 | 2,018 | 25 | 20,456 |
| 1000 | 28,216 | 126 | 715,802 |

- 奖励定位为「少量补给」，不替代穿越星球本身的产出。
- 修复后 `state.rift.open = false`，卡片显示「已修复 · 下次穿越成功后生成第 N 层裂缝」；裂缝视图展示下一道裂缝的预览奖励。

## 4. 动作槽与互斥

裂缝战斗与普通战斗、锁妖塔、星球运转、伐木等共用全局单一动作槽：

- `startRift()` 先 `planetInterrupt()` 中断星球巡航，再 `cancelCombat()` 清空普通战斗 / 塔战瞬态，然后写入 `state.action = { skill: 'rift', id: 'repair' }`。
- 反过来，`startAction()` / `startCombat()` / `startTower()` / `startDungeon()` / `planetStart()` 都会中断裂缝战斗；`cancelCombat()` 会把 `state.skills.combat.rift = -1`，不残留目标。
- `cycleTick()` 对 `rift` 直接跳过，裂缝战斗没有周期产出。
- 读档时进行中的裂缝战斗不恢复（与塔战一致），但 `state.rift.open / tier` 保留。

裂缝战斗的进度条使用「已打掉的血量比例」：`1 - target.hp / target.maxHp`，可正常显示到 100%（击杀瞬间动作槽释放、进度条消失，与锁妖塔一致）。

## 5. 存档

`state.rift = { open, tier }`：

| 字段 | 含义 |
| --- | --- |
| `open` | 是否存在未修复裂缝 |
| `tier` | 当前裂缝层级（生成时的穿越次数，0~10000） |

迁移规则（`mergeState`）：

- 有合法 `rift` 字段：`open` 取布尔值；`tier` 取整并夹到 `[0, RIFT.MAX_TIER]`，且不超过当前 `planet.cross`。
- 旧档（无 `rift` 字段）：兜底为「有一个未修复裂缝」，层级 = `min(planet.cross, max(0, 战斗等级 - 1))`。
  - 这样既不会直接白送一次穿越，也不会让「高穿越次数 / 低战斗等级」的老存档拿到无法战胜的高层裂缝而永久卡住。
- 进行中的裂缝战斗（`skills.combat.rift >= 0`、`action.skill === 'rift'`）是瞬态：读档时一律清空，不恢复目标与动作。
- 修复状态会落盘：`open = false` 读档后仍为已修复，可正常穿越；穿越成功后重新写入 `{ open: true, tier: 新穿越次数 }`。

## 6. 界面

- **星球面板卡片**：图标 + 「异界裂缝 · 第 N 层」+ 状态文案 + 「进入 ›」；未修复时边框高亮、图标脉冲，并在侧栏「穿越星球」上显示 `!` 角标。
- **裂缝战斗视图**：层级 / 状态 / 穿越限制、妖物名称与属性、生命条、开战（或停止）按钮、返回星球按钮、奖励预览、规则与公式说明。
- **穿越按钮**：未修复时 `disabled` 且提示「需先修复异界裂缝（第 N 层）」；修复后恢复可用。
- 所有图标均为 Unicode 6.0~12.0（🌀 👾 🕳️ 🦋 👻 💀 🐉 🗿），避免 Win10 方框。

## 7. 验证清单

- 新档 `state.rift = { open: true, tier: 0 }`，星球面板出现未修复裂缝卡片。
- 灵气充足时未修复裂缝仍拦截穿越，按钮置灰且提示「需先修复异界裂缝」。
- Lv1 新档可击败第 0 层：约 24~29 秒、承伤约 6~13，奖励灵石 / 星砂 / 战斗经验入账。
- 修复后可穿越；穿越成功立刻生成 `tier = 穿越次数` 的新裂缝，按钮再次置灰。
- 裂缝生命 / 攻击 / 命中 / 闪避 / 减伤随 tier 单调上升，出手间隔单调下降并止于 2.0 秒。
- 高层单次伤害不超过玩家生命上限 18%。
- 阵亡后 `state.rift` 保持未修复，`planet.cross` 不变，动作槽释放，可再次进入。
- 旧档无 `rift` 字段 → 兜底未修复裂缝，层级按 `min(cross, 战斗等级-1)`。
- 读档不恢复进行中的裂缝战斗，但未修复 / 已修复状态保留。
- 与星球、锁妖塔、普通战斗、伐木互相中断，`skills.combat.rift` 正确复位为 -1。
- 动作条裂缝进度可显示到 100%，战斗期间 `#content` 与 `.riftwrap` DOM 不重建。

## 8. 风险与后续

- 裂缝强度与玩家战斗成长并非强绑定：纯星球玩家可能在某些层级暂时打不过，需要先通过普通战斗 / 锁妖塔提升战斗等级或补装备。这是有意的软门槛，不是永久锁死。
- `HIT_CAP` 只限制单次承伤，不限制总战损；如果玩家输出严重不足，仍可能被持续消耗击败。后续可根据实测考虑增加「战斗时长上限」或「裂缝层数回落」选项，但当前版本不引入。
- 裂缝奖励刻意压低，避免与穿越星球、锁妖塔形成收益竞争；若后续需要提高存在感，优先调整战斗经验而不是灵石。
