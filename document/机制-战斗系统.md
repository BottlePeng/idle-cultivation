# 机制 · 战斗系统

> 相关代码：`js/data.js`（`MONSTERS`）、`js/engine.js`（`calcStats/hitChance/combatTick/onMonsterKilled/onPlayerDeath/autoEatTick/startCombat`）

战斗参考《梅尔沃放置》的**命中制（hit-chance）**模型：双方按各自节奏出手，命中率由「命中 vs 闪避」决定，伤害带浮动，减伤按防御折算。

---

## 1. 玩家属性（`calcStats`）

```
攻击 = BASE_ATK(5) + (战斗等级−1) × 2 + 装备atk
防御 = BASE_DEF(1) + (战斗等级−1) × 1.5 + 装备def
命中 = BASE_HIT(12) + (战斗等级−1) × 2.2 + 装备hit
闪避 = BASE_EV(8) + (战斗等级−1) × 1.6 + 装备ev
生命 = BASE_HP(60) + (战斗等级−1) × 8 + 大境界数 × 20 + 装备hp
```

随后依次乘：

1. **大境界倍率**：`×(1 + realmIndex × 0.12)`（攻/防/命/闪）。
2. **阵法加成**（玄机阵 & 金刚阵 & 聚灵阵）：
   - `atk × (1 + formBonus('atk'))`
   - `def × (1 + formBonus('def'))`
   - `hit × (1 + formBonus('hit'))`
   - `ev × (1 + formBonus('ev'))`
   - `hp × (1 + formBonus('hp'))`

**伤害减免**：`dr = min(0.75, def / (def + 140))`。

**伤害区间**：`atkMin = atk×(1−0.18)`，`atkMax = atk×(1+0.18)`（最小 1，保底伤害）。

**出手间隔**：玩家固定 `2.4s`（`PLAYER_ATTACK_TIME`）。

---

## 2. 命中判定（`hitChance`）

```
命中率 = clamp( 攻击方命中 / (攻击方命中 + 防守方闪避), 0.20, 0.95 )
```

- 玩家命中 vs 妖兽闪避；妖兽命中 vs 玩家闪避。
- 上下限 20% ~ 95%，避免「必中 / 必失」。

---

## 3. 战斗循环（`combatTick`）

```
若未选择妖兽：直接返回
若当前无目标或目标已死：
    respawn -= dt；到点则 spawnTarget()（复制妖兽属性为新目标）
否则：
    玩家计时器累计 → 每满 2.4s 出手一次（可一帧补多次）
        命中 → 伤害 = rollRange(atkMin,atkMax) × (1 − 妖兽dr)
        目标 HP ≤ 0 → onMonsterKilled()
    妖兽计时器累计 → 每满 m.interval 出手一次
        命中 → 伤害 = rollRange(m.atkMin,m.atkMax) × (1 − 玩家dr)
        玩家 HP ≤ 0 → onPlayerDeath()
```

- 战斗**占用动作槽**（`state.action = { skill:'combat', id:monsterId }`）。
- 只有「讨伐」状态才推进；停止后 `combatTick` 不再刷新目标。

## 5. 击杀与战败

### 5.1 击杀（`onMonsterKilled`）

- 灵石 `+= round(randInt(m.gold) × (1 + formBonus('gold')))`。
- `stats.kills++`；`addXp('combat', m.xp)`。
- 精通：按**怪物 id** 独立成长（`addMastery(m.id, round(m.xp × 0.6 × (1 + formBonus('mastery'))))`）。
- 掉落结算（见上）。
- 写入目标清空、计时器归零，`respawn = m.respawn`。

### 5.2 战败（`onPlayerDeath`）

- 生命置 `1`，`stats.deaths++`。
- **自动停止战斗动作槽**，退出讨伐并提示「先疗伤或备好食物再战」。

## 6. 生命恢复

| 途径 | 效果 | 是否占槽 |
| --- | --- | --- |
| 脱战回血（被动） | 每 10s 恢复 3% 生命上限（受「脱战回血」阵纹加成） | 否 |
| 灵气疗伤 | 消耗 25 灵力，恢复 40% 生命上限 | 否 |
| 打坐吐纳 | 每次 +8 生命 | **是** |
| 食物 | 按食物回血值恢复 | 否（自动进食） |
| 疗伤丹 | 恢复 65% 生命上限 | 否 |

### 6.1 自动进食（`autoEatTick`）

- 条件：开启自动进食 & 正在战斗 & `hp/maxHp ≤ ui.eatRatio`（可选 25/35/50/65%）。
- 选粮策略：`ui.eatFood = 'auto'` → 选**回复量最高**的持有食物；否则指定食物。
- 每次只吃 1 份，**不占用动作槽**。

## 7. UI 表现

- **战斗面板**：妖兽列表（等级门槛、掉落预览）+ 「搜寻 / 讨伐」状态。
- **对战视图**：双方血条（`data-bar="hp"` / `data-bar="monster"`），走增量刷新。
- **右侧角色卡**：攻击 / 命中 / 闪避 / 减伤；自动进食开关与阈值下拉。
- **见闻日志**：击杀、掉落、战败等事件流水。

---

## 8. 扩展指引

- 新增妖兽：在 `MONSTERS` 追加一条（含 `drops`），无需改引擎。
- 新增加成来源：在阵法 `mods` 增加对应 `key`（如 `atk/drop/gold`），`calcStats` / `onMonsterKilled` 自动生效。
- 若引入新战斗属性（如暴击），需同步 `calcStats`、`combatTick`、UI 三处。
